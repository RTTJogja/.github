# RTTJogja Organization Profile Card

This project publishes a compact public card on the RTTJogja GitHub
organization profile. The card introduces RTTJogja, points visitors to its
public destinations, and briefly highlights work already published by the
organization.

The root `README.md` is the project definition. The card shown to visitors is
maintained in [`profile/README.md`](profile/README.md).

## Purpose

The organization profile card should answer three questions:

- What is RTTJogja?
- Where can visitors find its website and contact details?
- What public work has RTTJogja already published?

It is not a standalone website, a complete repository catalog, or a substitute
for documentation in the referenced repositories.

## Official GitHub Layout

GitHub displays a public organization profile README when:

- the organization owns a repository named `.github`
- the `.github` repository is public
- the card is stored at `profile/README.md`

Reference: [Customizing your organization's profile](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile)

This workspace is the public [`RTTJogja/.github`](https://github.com/RTTJogja/.github)
repository.
