# RTTJogja Organization Profile Card

This context defines the language used for RTTJogja's compact public overview
on GitHub.

## Language

**RTTJogja**:
The community represented by the public `RTTJogja` GitHub organization.

**Organization profile card**:
The concise public overview shown on the RTTJogja organization Overview tab.
_Avoid_: Landing page, website, repository catalog

**Profile README**:
The `profile/README.md` artifact in the public `RTTJogja/.github` repository
that GitHub renders as the organization profile card.
_Avoid_: Root README, GitHub Pages site

**Public work reference**:
A brief, evidence-based summary that links to work published in a public
RTTJogja repository without duplicating that repository's documentation.
_Avoid_: Project copy, full project documentation
